# Archived AGENTS.md patch versions

**Install the [latest verified patch](../../guides/AGENTS.waiting-compatible.md).** It remains at `docs/guides/AGENTS.waiting-compatible.md` and is the only current distribution copy. See its [Japanese explanation](../../guides/AGENTS.waiting-explanation.ja.md) and the [repository README](../../../README.md).

This directory holds earlier proposals and frozen benchmark inputs. Names such as `recommended`, `final`, and `compact-final` describe their historical stage and do not identify the current recommendation. The `wording-no-pragma` snapshot matches the current patch byte for byte; it is archived here as experiment evidence.

All patch contents and hashes are preserved. The original directory structure is retained under this archive. Frozen JSON manifests, captured trial records, and raw session logs keep the paths recorded at the time. The [path index](paths.json) maps those paths to the archived files; the benchmark tools resolve them through [patch_paths.py](../../waiting-benchmark/patch_paths.py). Maintained documentation and live reproduction commands use the new locations.
